# Restyle — статус проекта (13.09.2026)

Все фазы плана закрыты (1–7 — по ТЗ, 8–10 — правки по живому тесту).
Архитектура, контракт IPC и принятые решения — в `CLAUDE.md`, обзор — в `README.md`,
незакрытое — в `docs/TODO.md`.
Установщик: `src-tauri/target/release/bundle/msi/Restyle_0.1.0_x64_{ru-RU,en-US}.msi`.

## Что работает

**Хоткеи и панель.** LL-хук клавиатуры: основная комбинация (Ctrl+Alt+R), undo
(Ctrl+Alt+Z), исправление раскладки («Ctrl, Ctrl»), своя комбинация на стиль.
Двойное нажатие модификатора — полноценная комбинация (`HotkeyCombo.double`).
Короткое нажатие основной комбинации может применять стиль, удержание рисует
кольцо у курсора и открывает панель. Панель у курсора без кражи фокуса,
Enter/Esc/R/Tab/стрелки/1–9 — через хук, все стили видны чипами.

**Захват текста.** UIA (ValuePattern / TextPattern, выделение и каретка, поля
паролей не читаются) → буфер обмена (Ctrl+A/Ctrl+C, снапшот всех форматов,
восстановление сразу после чтения). В приложениях из списка «только выделение»
(IDE, Word, Obsidian…) — только выделенный фрагмент.

**Скриншот.** Окно с фокусом или монитор: BitBlt → 1280 px → JPEG q70.
Выключатель, тумблер у стиля, список исключений (менеджеры паролей, банки).

**Генерация.** Gemini SSE-стриминг, минимум размышлений, каталог моделей с
ключа (белый список текстовых `gemini-*` flash/pro), Esc рвёт HTTP-стрим.
Перевод — DeepL (Free/Pro по ключу), без ключа — модель; «после перевода
причесать стилем».

**Локальные преобразования** (`textfx.rs`). Регистр из кнопки «Aa Регистр» в
панели; исправление раскладки EN ↔ RU/UK с автоопределением направления и
переключением раскладки окна. Оба учитывают выделение: меняется только
выделенный фрагмент, вклеивается в текст поля, выделение/каретка
возвращаются на место (`uia::select_range`).

**Вставка и undo.** UIA `SetValue` или Ctrl+A/Ctrl+V с восстановлением буфера;
ранний Enter вставляет по готовности; автовставка для быстрых стилей; проверка,
что окно не сменилось. Undo последней или любой записи истории; для
«только выделение» — в буфер.

**Окна.** Настройки из шести разделов (модель и ключ, хоткеи, стили,
приватность, вставка и история, интерфейс), окно истории, мастер первого
запуска, своё меню трея (история, undo, автозапуск, выход). Стили:
добавление, удаление (и встроенных — с возвратом), перетаскивание порядка,
тип «перевод», скриншот и хоткей у стиля. Темы, шесть акцентных цветов, три
языка, ссылка на репозиторий.

## Замеры (релиз)

| Метрика | Значение |
|---|---|
| Хоткей → отрисованная панель с текстом (UIA) и снятым кадром | 52–61 мс |
| То же через буфер обмена | ≈100 мс |
| Захват текста UIA | 13–22 мс |
| Кадр окна + кодирование | 8 + 24 мс |
| Первый чанк `gemini-3.5-flash-lite` / `gemini-3.6-flash` | 0,7–1,5 с / до 2,9 с |
| CPU в простое (всё дерево процессов) | 0,02 % |
| Приватная память всего дерева (restyle + вебвью) | 107–136 МБ |
| Сам `restyle.exe` | 28–38 МБ |

Скрипт — `scripts/perf_release.ps1`: считает CPU и память по дереву процессов
(вебвью живут в отдельных `msedgewebview2.exe`) и кликает в поле перед
демо-хоткеем, иначе UIA видит форму вместо поля.

## Как проверять

```
pnpm install && pnpm tauri dev          # приложение
cd src-tauri && cargo test               # 79 юнит-тестов + экспорт ts-rs
python scripts/mock_gemini.py 8765       # мок SSE (ключи bad-key / rate / slow)
pwsh -File scripts/e2e_paste.ps1         # вставка/undo в Блокноте
pwsh -File scripts/e2e_settings.ps1      # быстрый стиль, история, окно настроек
pnpm tauri build                         # релиз + MSI (WiX, ru-RU и en-US)
pwsh -File scripts/perf_release.ps1      # замеры на релизе
```

Отладочная сборка без `custom-protocol` берёт фронтенд с `devUrl` (Vite :1430),
а не из `dist`: для проверки UI на debug-бинаре нужен запущенный `pnpm dev`.
Любой скрипт, который пишет `settings.json`, обязан вернуть его в `finally`.

## Отклонения от ТЗ (осознанные)

- `xcap` заменён на собственный BitBlt: PrintWindow давал ~110 мс на окно.
- Буфер обмена восстанавливается сразу после чтения, а не после вставки.
- Дефолтная модель `gemini-3.5-flash-lite`: `gemini-2.5-*` недоступны новым
  ключам (404), у 3.6-flash первый чанк заметно медленнее.
- Undo в режиме «только выделение» кладёт исходник в буфер, а не вставляет.
- Встроенные стили можно удалять (просьба после первого теста).
- Меню трея и список регистров — своё окно, а не системное меню.

## История правок

**Фаза 8 — первый живой тест.** Свой значок (`scripts/make_icons.py`) и своё
меню трея; перевод через DeepL; короткое/долгое нажатие с кольцом; секции и
перетаскивание стилей; каталог моделей с ключа; выбор процессов из запущенных;
тосты-подтверждения убраны, оставшиеся — по размеру текста. Починено: окна без
записи в `capabilities/default.json` не получали события; меню открывалось на
стартовой высоте; HTML5 drag&drop перехватывался Tauri
(`disable_drag_drop_handler`).

**Фаза 9 — вторая волна.** Все чипы в панели; удаление встроенных стилей и
«Вернуть стандартные» для списков процессов; белый список моделей; у оверлея
убраны акрил и DWM-рамка (`window::clear_dwm_frame`) — акрил DWM рисует на всё
окно, `SetWindowRgn` композиция WebView2 игнорирует; короткое нажатие в пустом
поле — только тост.

**Фаза 10 — третья волна.** Вкладка «Интерфейс» (тема, акцентный цвет через
CSS-переменные, язык); свой выпадающий список (`Select`) и оверлей «Нажмите,
чтобы изменить» у хоткеев; окна из меню трея выходят поверх всех
(`window::force_foreground`); регистр в панели; исправление раскладки;
учёт выделения и возврат каретки; список регистров в окне меню (панель не
двигается, список — под кнопкой или над ней); хоткеи «Ctrl, Ctrl».
Починено: каретка в конце текста в Telegram превращалась в выделенный последний
символ (отмер от конца документа); «Ctrl, Ctrl» не отображалась в настройках.

## Известные ограничения

- Возврат каретки работает только через UIA TextPattern; в приложениях, где
  текст читается буфером обмена, каретка после вставки — в конце текста.
- Watchdog хука иногда ложно переустанавливает его при чисто мышиной
  активности (идемпотентно).
- UWP-приложения видны как `ApplicationFrameHost.exe` в списках процессов.
- Первое обращение UIA к Chrome включает у него accessibility-режим.
- Пока окно настроек открыто, глобальные хоткеи работают; хук молчит только на
  время захвата комбинации.
- Окна нельзя создавать из главного потока Tauri (`build()` ждёт событийный
  цикл, который сам же заблокирован) — команды `open_*_window` асинхронные.
- Скруглённые углы окон даёт DWM (Windows 11); на Windows 10 углы прямые.
- MSI не подписан — SmartScreen предупредит при первом запуске.
- Каталог моделей показывает всё, что отдал ключ; часть моделей может отвечать
  404 — проверяется только запросом.
- Память: постоянных вебвью два (панель и меню трея), приватный набор дерева
  временами выше 120 МБ. Ужаться можно, создавая меню по первому клику.
