# Незакрытые задачи

- Проверить руками возврат каретки после «Исправить раскладку» и регистра:
  каретка в середине текста, эмодзи перед кареткой (UTF-16 против единиц UIA),
  Chrome/Word/Блокнот. Если поплывёт — хранить сам `IUIAutomationTextRange`
  выделения рядом с элементом последнего чтения вместо числовых смещений.
- Список регистров у нижнего края экрана: убедиться, что открывается над кнопкой.
- Живым ключом прогнать `list_models` и убедиться, что в списке только
  текстовые Gemini (фильтр покрыт тестом `catalog_keeps_only_text_gemini`).
- Тест на `normalize`: удалённый встроенный стиль не возвращается, а пустой
  список стилей заменяется встроенными.
- Скриншоты актуального интерфейса для README.
- Память: окно меню трея создавать по первому клику, если критерий < 120 МБ
  станет важнее задержки первого открытия.
